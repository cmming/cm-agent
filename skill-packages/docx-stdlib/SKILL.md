# 标准库 Word 文档生成

将用户内容整理为 JSON，调用当前技能固定的 `scripts/main.py`。使用 `zipfile` 和 `xml.etree.ElementTree` 创建真实 OOXML 文档，不把 Markdown 或 HTML 改名为 DOCX，不安装依赖，不生成或执行额外代码。

## 使用方式

1. 实际加载本技能后阅读 [输入契约](references/input-format.md)，按需要参考 [示例](examples/sample.json)。保留用户原意，未提供的信息不要编造。
2. 调用 `run_skill_script`：`skillId` 取本轮技能目录标识；`path` 固定为 `scripts/main.py`；`stdin` 为 UTF-8 JSON 文本。输入总量最多 32768 字节，必要时精简内容，不把同一文件拆成多次覆盖调用。
3. 脚本使用服务端 `CM_AGENT_ARTIFACT_DIR` 输出 `.docx`。标准输出只包含状态、文件名、大小和摘要，不输出文件字节、Base64 或下载地址。
4. 脚本返回 `created` 仅表示生成成功；等待 Run 成功且控制台出现文件产物后，提示用户通过系统附件下载。不得声称仅凭文件名或标准输出已交付可下载附件。

管理员需启用技能沙箱及文件产物收集，并允许 `.docx`。导入后按系统既有流程完成候选 TEST、发布和 Agent 绑定；包本身不修改配置、不授予权限。文件产物关闭时明确说明环境未就绪，不改用标准输出传送二进制。

## 内容与范围

支持中文标题、副标题、一至三级标题、普通段落、项目符号与编号列表、简单矩形表格、显式分页及页码。默认 A4、中文宋体、11 磅正文；可选择 Letter 和横向页面。表格表头重复，单元格自动换行。

需要可编辑图表、图片、复杂公式、目录自动刷新、合并单元格、模板套版或原文件修订时，应说明本技能边界；不要把不支持的结构伪装成已实现功能。段落中的 Markdown 按普通文字处理。

脚本错误包含安全中文原因、`errorCode` 和关联 `errorId`，不重复盲目执行。参数错误应修正 JSON 后再调用；授权、收集、发布或下载错误沿用 CM Agent 自身诊断。生成器不读取文件路径、网络地址或可执行表达式。字体与分页效果由用户 Word/WPS 环境决定；结构检查通过不等于已完成所有内容的视觉验收。
