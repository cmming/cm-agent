本机客户端

登记运行客户端的电脑，供后续会话选择。本页只显示服务端配对状态，不显示设备在线状态。

连接新电脑

在要执行操作的电脑上准备客户端，浏览器可以在另一台电脑使用。

  1. 准备客户端

    在构建电脑使用 JDK 21 和 Maven 3.9+ 构建 cm-agent-local-client 模块，然后把生成的 -all.jar 复制到目标电脑。目标电脑只需 JDK 21，不需要 Maven、源码或其他依赖目录。服务端需在隔离测试环境启用本机客户端功能，远程访问需使用已配置的 HTTPS 地址。

    查看源码构建命令

    在项目源码根目录运行：

    mvn -pl cm-agent-local-client -am -DskipTests package

    可执行文件位于 cm-agent-local-client/target/cm-agent-local-client-0.1.0-SNAPSHOT-all.jar；版本号变化时按构建输出替换。

  2. 生成配对包

    在目标电脑的交互式终端运行下面的配对命令，将服务端地址和设备名称换成实际值。保留终端打开，按提示设置本机身份口令（如需要），复制完整 JSON。

    配对命令
    java -jar cm-agent-local-client-0.1.0-SNAPSHOT-all.jar pair --server https://服务端地址 --name 设备名称

    Windows、Linux 和 macOS 使用相同命令。本机同机测试可使用服务端已配置且允许的回环地址；不要将 localhost 当作另一台电脑的服务端地址。

  3. 核对并确认配对

    将 JSON 粘贴到下方，核对设备名称和平台属于目标电脑，再确认配对。浏览器确认后，回到客户端终端等待“配对完成”；服务端显示已登记不代表客户端已完成或在线。

  4. 启动客户端并选择单轮授权

    配对完成后，在目标电脑运行以下命令并保持客户端运行。然后到会话聊天选择设备、本轮允许的能力和确认方式，再发送任务。

    查看启动命令

    在 fat JAR 所在目录的交互式终端运行；如设置过身份口令，按提示输入。

    java -jar cm-agent-local-client-0.1.0-SNAPSHOT-all.jar run

配对只登记设备，不授予文件、联网或命令操作权限；每次运行仍需在会话中选择设备、能力和确认方式，并受现有权限与审批策略约束。

浏览器只转交客户端签名的设备身份。请核对生成配对包的电脑；服务端确认后仍需等待该客户端完成配对。

待连接设备——

“完全访问”仅在后续运行中选择，并在已授权能力和服务端策略范围内生效。命令继承客户端运行账号的操作系统权限，可能访问项目外资源并产生不可逆变化。

授权边界

作用对象
生成配对包并运行客户端的电脑及其操作系统账号；浏览器可能在另一台电脑。
生效时间
每轮 Run 单独选择；Run 结束或审批等待取消后失效。
服务端约束
租户、原主体、Agent、会话、Run、设备签名、工具能力与审计必须同时有效。
结果未知
断线、超时或停止不会自动重放，也不会承诺回滚已经发生的外部副作用。
