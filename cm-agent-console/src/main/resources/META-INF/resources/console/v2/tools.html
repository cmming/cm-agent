HTTP 配置填写指南

页面按树形结构录入参数，字段名称直接作为 PATH、QUERY 或 HEADER 名称；保存时会自动转换为后端需要的扁平参数数组。

GET 适合查询，不能使用 BODY 或 BODY_ROOT；POST 可以提交对象或根数组请求体。完整示例使用 POST。

填写已加入服务端白名单的完整地址。{orderId} 必须与 PATH 参数字段名完全一致；QUERY 参数由参数列表自动追加。

查看地址样例
https://api.example.com/orders/{orderId}

接口没有输入参数时可以保持为空；需要参数时先添加顶层参数，再在 OBJECT 或 ARRAY 节点内添加子参数。子节点按层级缩进展示；ARRAY 只能有一个匿名元素节点。

0 个参数

当前工具没有输入参数，可直接保存；接口需要参数时再添加顶层参数。

查看参数层级规则
orderId                  STRING · PATH
payload                  ARRAY  · BODY_ROOT
└─ 数组元素               OBJECT
   ├─ p1                 STRING
   └─ enabled            BOOLEAN

BODY_ROOT 会把命名输入字段的值直接作为整个请求体，因此可以生成 [{"p1":"v1"}] 这样的根数组。

键是请求头名称，值只能是以 secret/ 开头的引用。请勿填写、粘贴或展示 Token、API Key 等真实 Secret 值。

查看 Secret 引用样例
{
  "Authorization": "secret/integration/orders-token"
}

真实值由服务端运行时解析，不会保存在 Tool 配置中。

允许范围为 100–30000 毫秒。示例：3000 表示最多等待 3 秒，包含 Secret 解析、请求和重定向耗时。
