本机客户端

登记运行客户端的电脑，供后续会话选择。本页只显示服务端配对状态，不显示设备在线状态。

连接新电脑

在要执行操作的电脑上准备客户端，浏览器可以在另一台电脑使用。

  1. 准备客户端

    在构建电脑使用 JDK 21 和 Maven 3.9+ 构建 cm-agent-local-client 模块，然后把生成的 -all.jar 复制到目标电脑。目标电脑只需 JDK 21，不需要 Maven、源码或其他依赖目录。服务端需在隔离测试环境启用本机客户端功能；客户端使用部署中显式配置并允许的 HTTP 或 HTTPS 服务地址。

    查看源码构建命令

    在项目源码根目录运行：

    PowerShell / Bash
    mvn -pl cm-agent-local-client -am -DskipTests package

    可执行文件位于 cm-agent-local-client/target/cm-agent-local-client-0.1.0-SNAPSHOT-all.jar；版本号变化时按构建输出替换。

  2. 生成配对包

    在目标电脑的交互式终端运行下面的配对命令，将服务端地址和设备名称换成实际值。保留终端打开，按提示设置本机身份口令（如需要），复制完整 JSON。

    配对命令与全部参数
    命令 pair
    java -jar cm-agent-local-client-0.1.0-SNAPSHOT-all.jar pair --server http://服务端地址:端口 --name 设备名称

    复制后请替换命令中的中文占位符。Windows、Linux 和 macOS 使用相同参数。

    --server <URL>必填
    服务端 HTTP/HTTPS 规范来源，例如 http://192.168.1.10:8080。只允许根来源，不接受查询、片段或子路径，且必须与部署 audience 和允许来源完全一致。
    --name <设备名称>必填
    用于浏览器核对的目标电脑名称，长度为 1–120 个字符。
    --state-dir <目录>可选
    保存设备身份和本地见证的位置。默认 Windows 为 %USERPROFILE%\.cm-agent\local-client，Linux/macOS 为 $HOME/.cm-agent/local-client；指定后后续 run 必须使用同一目录。
    --credential-backend system|password可选
    设备私钥的保存方式。未指定 --state-dir 时默认 system；指定 --state-dir 时默认 password。自定义状态目录必须先使用 password，不能与 system 组合。
    --password-stdin可选标志
    仅用于 password 凭据后端，从标准输入读取口令；pair 需要输入两次相同的非空口令。普通交互式终端可省略，由程序安全提示输入。

    system 使用操作系统凭据存储；password 使用受口令保护的本地密钥文件。使用 HTTPS 时仍由 JVM 校验服务器证书和主机名；不要将 localhost 当作另一台电脑的服务端地址。

  3. 核对并确认配对

    将 JSON 粘贴到下方，核对设备名称和平台属于目标电脑，再确认配对。浏览器确认后，回到客户端终端等待“配对完成”；服务端显示已登记不代表客户端已完成或在线。

  4. 启动客户端并选择单轮授权

    配对完成后，在目标电脑运行以下命令并保持客户端运行。然后到会话聊天选择设备、本轮允许的能力和确认方式，再发送任务。

    启动命令与全部参数

    在 fat JAR 所在目录的交互式终端运行；如设置过身份口令，按提示输入。

    命令 run
    java -jar cm-agent-local-client-0.1.0-SNAPSHOT-all.jar run

    --state-dir <目录>可选
    必须与配对时使用的状态目录一致；省略时使用当前用户的默认目录。启动命令不再接收 --server 或 --name，服务端来源和设备身份均已从该目录读取。
    --credential-backend system|password可选
    必须与配对身份的实际保存方式一致。未指定 --state-dir 时默认 system；指定 --state-dir 时默认 password。
    --password-stdin可选标志
    仅用于 password 凭据后端，从标准输入读取一次解密口令；普通交互式终端可省略。

配对只登记设备，不授予文件、联网或命令操作权限；每次运行仍需在会话中选择设备、能力和确认方式，并受现有权限与审批策略约束。

浏览器只转交客户端签名的设备身份。请核对生成配对包的电脑；服务端确认后仍需等待该客户端完成配对。

待连接设备——

“完全访问”仅在后续运行中选择，并在已授权能力和服务端策略范围内生效。命令继承客户端运行账号的操作系统权限，可能访问项目外资源并产生不可逆变化。

授权边界

作用对象
生成配对包并运行客户端的电脑及其操作系统账号；浏览器可能在另一台电脑。
生效时间
每轮 Run 单独选择；Run 结束或审批等待取消后失效。
服务端约束
租户、原主体、Agent、会话、Run、设备签名、工具能力与审计必须同时有效。
结果未知
断线、超时或停止不会自动重放，也不会承诺回滚已经发生的外部副作用。
