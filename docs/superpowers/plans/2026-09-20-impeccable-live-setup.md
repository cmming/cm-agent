# Impeccable Live 本地配置计划

1. 启动 Live 引导，识别缺失配置。
2. 核对本地 HTTP 服务、资源实际加载目录和 CSP。
3. 写入 Live 配置并再次启动辅助服务。
4. 打开受控浏览器到 v2 工具治理页并保持轮询。
5. 在用户选择、接受或退出后执行 Live 规定的清理与验证。
