# Impeccable 产品初始化计划

1. 阅读技能初始化流程与项目 README，确认产品文件及工作流配置不存在。
2. 通过结构化问题确认主要用户和新增页面的制作默认值，收到实际回答后再写入。
3. 创建 `PRODUCT.md` 与 `.impeccable/config.json`；不将工作流偏好复制到产品事实中。
4. 完成同主题设计、实现说明和进度账本。
5. 检查平台与版本标记、JSON 值、相对文档链接及差异；不运行与文档初始化无关的 Maven 或浏览器测试。
