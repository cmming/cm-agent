# 强制生成既定范围内代码注释实施计划

关联设计：[设计说明](../specs/2026-09-01-mandatory-comment-generation-design.md)。

## 任务

1. 在 `AGENTS.md` 的“代码注释与 JavaDoc 规范”中增加强制生成条款。
2. 复核条款仅约束已判定需要注释的代码，不改变既有范围。
3. 检查差异，确认未修改业务代码或用户已有工作区改动。
4. 记录实际实现、验证结果和提交状态。

## 验证方式

- 检查新增条款同时包含“必须实际生成”和“不扩大既有范围”。
- 使用 `git diff --check` 检查文本格式。
