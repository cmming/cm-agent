# 控制台视觉与交互精修实施计划

1. 使用真实登录账号建立七页桌面与移动端截图基线。
2. 在 `multipage.css` 末尾收口聊天、运行、审计和资源列表的工作区高度。
3. 恢复移动端总览、聊天页的单列布局，并优化移动端标题操作区。
4. 调整移动端运行记录排版和工具操作按钮网格。
5. 在 `app.js` 中增加移动端当前导航项自动居中。
6. 升级静态资源查询版本并补充结构回归测试。
7. 执行 Java 21 控制台模块测试、JavaScript 语法检查和 Playwright 浏览器回归。

设计依据见 `../specs/2026-09-16-console-visual-interaction-polish-design.md`，最终结果见 `../implementation/2026-09-16-console-visual-interaction-polish-implementation-design.md`。
