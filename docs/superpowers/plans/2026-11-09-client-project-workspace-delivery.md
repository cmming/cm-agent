1. 先验证提案不启动进程、敏感参数被拒绝、工具链/构建配置变化使旧许可失效，再验证审批版本、摘要和 `displayExact` 不匹配时零副作用拒绝。
2. 客户端合同验证固定环境、显式异步启动、有界输出、状态、停止、已观察后代进程退出、重启回执 UNKNOWN 和客户端关闭等待；Java 测试必须串行执行，避免共享 `target/`。
3. Server 合同验证仅提议命令通过、已执行失败/超时不通过、屏障预算不占 HTTP/JDBC 事务、异步 RUNNING 保留停止控制、重复停止不重复派发，以及超时 STOP_REQUESTED→UNKNOWN。
4. 运行 Node 命令预览/停止/UNKNOWN 页面门禁、AgentScope 受保护载荷、V29 静态双方言检查、全模块跳过测试编译打包和 `git diff --check`。
5. Rocky PostgreSQL/MySQL、真实 Windows、TLS、Provider、浏览器窄屏/键盘、断电/注销和进程树故障仍由 T9 受控环境执行；未满足版本与资源门禁时明确保持阻塞。
