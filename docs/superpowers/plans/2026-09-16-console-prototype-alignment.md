# 控制台原型对齐实施计划

1. 对照已发布原型核对导航、顶栏、标题区、卡片和运行调试区的结构。
2. 修改七个 v2 HTML 页面，将标题和操作迁移到内容区，保留原有表单 ID 与访问路径。
3. 在 `multipage.css` 增加统一视觉规则和窄屏降级规则。
4. 为会话页新增的顶部“新会话”按钮复用既有创建会话处理函数。
5. 执行静态结构检查、JavaScript 语法检查与服务端控制台测试；使用运行中的控制台进行页面核验。
6. 修正管理区固定左栏和表单双列分组，补充结构回归测试，提升公共样式版本为 2.1.1；对运行中的模型配置页检查列表、详情及表单的实际排列。

设计依据见 `../specs/2026-09-16-console-prototype-alignment-design.md`，执行结果见 `../progress/2026-09-16-console-prototype-alignment-ledger.md`。
