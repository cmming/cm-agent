# Tool 工作区分阶段实施计划

关联设计：[Tool 工作区分阶段设计](../specs/2026-09-20-tool-workspace-stages-design.md)。

1. 在 `tools.html` 增加右侧详情容器，并将顶部注册入口改为可绑定的按钮。
2. 在 `app.js` 中维护选中 Tool，渲染详情，并以统一函数切换详情、定义、授权和调试面板。
3. 将未安装内置 LOCAL 示例渲染到左侧 Tool 列表；安装成功后进入调试阶段。
4. 更新静态资源版本及资源测试，执行语法、模块测试和差异检查。
5. 修复普通 Tool 重绘清空内置示例卡片的问题，并补充静态回归断言。
6. 移除已安装示例的显示过滤，按工具 ID 合并普通工具与目录，刷新时同时加载两份数据。
7. 登录后验证选择、编辑取消和刷新；以浏览器模拟空工具列表及两种接口完成顺序，检查移动端溢出。
8. 在详情添加 MCP 发布操作，复用专用发布接口；锁定 LOCAL 编辑中的发布状态，并验证普通保存不会误发布或误取消发布。
