## 执行顺序

1. **T0/T1：页面边界复核**。读取 `local-client.html`、`app.js`、`ConsoleResourceTest` 和服务端 LocalClient 接口，确认页面只负责配对、设备列表、详情和撤销。
2. **T2：配对包解析与确认**。验证 JSON 结构、设备名/平台预览、签名失败、重放、过期、不同主体和确认失败；确认前不得产生可用设备。
3. **T3：设备管理与撤销**。验证列表隔离、详情、撤销、重复撤销和撤销后的挑战拒绝；页面显示服务端权威结果。
4. **T4/T5：风险与状态提示**。检查账号权限、Run 失效、UNKNOWN、停止不回滚和不显示在线状态的文案；错误需含可读原因和关联编号。
5. **T6：页面资源清理**。移除重复或无关脚本引用，确认使用的 CSS/JS 版本和页面能力匹配。
6. **T7：Windows 联合回归**。在隔离客户端和浏览器环境完成配对、设备列表、撤销和一次受控 Run 选择；不使用生产凭据。
7. **T8：Linux/macOS 实机**。分别在真实桌面安装、启动、配对、撤销和执行一次受控操作；没有环境保持待做。
8. **T9：远程与生产门禁**。验证真实 TLS、多实例路由、长期空闲、多客户端限流、安装包和签名；未做不得写成完成。
9. **T10：最终一致性**。检查页面、聊天页设备选择、服务端设备和客户端协议使用同一租户/主体/Run 绑定。
10. **T11：授权模式边界**。核对 `ASK_ON_EFFECT`、`ASK_ON_RISK`、`FULL_ACCESS` 在聊天页的设备作用域；确认本页不提供模式入口，也不把项目模式用于设备。
11. **T12：配对生命周期与权限**。验证 `agent:run`/`agent:read` 权限、设备密钥存储、浏览器确认后客户端轮询和身份落盘；覆盖客户端退出、超时、落盘失败和“服务端已确认但客户端未完成”。
12. **T13：设备管理状态**。覆盖刷新、活跃/已撤销列表、详情字段、二次撤销、`expectedVersion` 冲突和跨账号隔离。
13. **T14：系统状态文案**。区分控制台/服务端健康、服务端配对状态和设备在线状态；必要时修正页面文案或辅助说明。

## 验证方法

- 控制台资源测试检查页面标识、风险文案和资源引用。
- Node/浏览器测试覆盖配对包解析、预览、确认、列表、详情、二次撤销和版本冲突。
- 服务端 MockMvc/集成测试覆盖非法签名、重放、跨主体、撤销和结果未知。
- Windows/Linux/macOS 客户端分别执行本机配对和受控操作；容器结果不能替代桌面实机。
- 详细命令、证据和未执行项写入账本。

## 完成标准

页面不执行操作、不伪报设备在线、不绕过客户端签名和服务端身份校验；三种模式、RBAC、配对落盘、设备管理和系统状态边界可观察；错误和安全边界清晰；所有未完成平台或远程 TLS 门禁保持明确状态。
