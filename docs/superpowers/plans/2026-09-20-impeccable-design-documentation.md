# Impeccable 设计系统归档计划

1. 加载 Impeccable 产品上下文与 `document` 流程，确认不存在现有 `DESIGN.md`。
2. 扫描共享 CSS 变量、最终覆盖规则、核心页面结构与响应式断点。
3. 登录本地控制台，采样总览和工具页的计算样式，检查桌面及窄屏布局。
4. 请用户确认整体意象与视觉边界；将回答归纳为“受控工作台”和“沿用当前克制风格”。
5. 写入 `DESIGN.md` 与 `.impeccable/design.json`，不修改应用实现。
6. 验证 Markdown 章节顺序、YAML 关键字段、JSON 结构、组件引用、相对链接及差异质量。
