# V3 聊天工作区实施清单

日期：2026-11-21；主题：`console-v3-workspace`；修订：R0；工作模式：`mode=default`；任务：T0～T5。

## 需求与范围

用户要求按照已交付 Sites 的布局改造当前项目，生成以聊天工作区为主的 V3 前端，保留现有功能并对接真实后端。视觉与布局依据见[独立 Sites 原型](https://cm-agent-codex-workspace.poetic-lark-9729.chatgpt.site/)。真实后端验收以本工作包账本为准。

分析基线为 `e70d9f869470e073420fccbdc5041eca9046702c`。V2 资源位于 `cm-agent-console/src/main/resources/META-INF/resources/console/v2/`；参考 Site 源码位于 `F:/java/cm-agent-sites/cm-agent-codex-20261120/`。既有功能与认证契约见[README](../../../README.md#服务访问与控制台)。

当前范围为新增 `/console/v3/` 登录、聊天、本地项目、能力总览、Agent、模型、工具、技能、运行、审计、本机客户端共十一个入口及固定短路径；V2 保持可访问。`/`、`/console` 等原有默认入口继续指向 V2，V3 登录后以聊天为默认页面；这是保留既有入口兼容性的实施取舍，见设计 D3。视觉参考不赋予改变权限、租户或业务约束的授权。

## 任务与验收

| 编号 | 目标与文件线索 | 依赖 | 可观察验收条件 | 验证方法 |
|---|---|---|---|---|
| T0 | 核对 V2、共享脚本、服务端控制台路由及当前接口契约 | 无 | 十一个入口及聊天、项目、管理能力具有对应源码依据；列明硬编码版本路径和复用边界 | CodeGraph 优先定位，复核模块 POM、README、现有测试与必要源码 |
| T1 | 新增 V3 版本化入口与统一工作台外壳 | T0 | V3 直接访问、登录、刷新、跨页、退出正确；V2 仍走其原有路径；JWT 不进入存储或 URL | 静态资源/路由测试、登录与刷新联调、权限拒绝检查 |
| T2 | 将真实普通聊天与项目工作流接入 Codex 式布局 | T1 | 项目和会话有稳定导航；消息、Agent、模型配置关系、文件引用、授权、审批、停止和错误反馈保留原语义；无演示数据或预设回答代替后端 | 既有聊天/项目测试、V3 布局契约测试、真实后端会话与关键操作联调 |
| T3 | 保留能力总览和八类管理工作流，并保留独立本地项目入口 | T1 | Agent、模型、工具、技能、运行、审计、本机客户端及相关配置操作仍调用既有 API；仅配对状态不宣称设备在线 | 现有业务回归、逐页切换与关键读写流程联调、授权与敏感字段检查 |

| T5 | 维护生产说明、发布说明、视觉说明及本六份工作包 | T0～T4 | 使用者能找到 V3 与兼容入口；文档对应实际代码；提示词可进入问答；实时状态和证据只在账本 | 链接、职责、范围一致性与差异检查 |

T3 中的八类管理工作流为能力总览、Agent、模型、工具、技能、运行、审计、本机客户端；本地项目同时属于独立入口和 T2 的聊天上下文，不因导航整合而被删除。

## 必要门禁

- 不复制 Site 的浏览器本地业务状态、模拟回答、虚构运行、审批或设备；测试替身仅能证明对应契约，不能冒充真实后端验收。
- 复用认证 Cookie、现有 API、SSE、租户、权限、工具授权、审批、审计和失败编号；不能由前端覆盖可信租户或扩大操作范围。
- 保留中文输入组合保护、停止期间发送锁、断线核对和草稿原有生命周期；变更失败分支须验证中文原因、错误码、错误编号及脱敏边界。
- 不覆盖既有脏文件，不修改旧原型工作包；未经指令不提交、推送或部署生产业务。
- Java 构建先核实 JDK 21；Docker、JDBC、Flyway、Testcontainers 检查仅在 `ssh rocky` 的项目容器环境执行，并核对待验源码。
