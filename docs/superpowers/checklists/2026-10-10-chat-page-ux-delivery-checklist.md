## 证据与验收条件

- 列表最多请求 50 条，只对当前已加载标题过滤；消息查询仍最多 200 条。
- 上翻、delta、执行过程和异步文件均经过跟随控制；同会话回读保存消息标识与相对位置，新会话跟随最新。
- TEXT 正文复制排除 THINKING、TOOL_USE、TOOL_RESULT 与审批；代码复制仅取 code 节点，失败只显示安全中文提示。
- 组合输入、229、重复 Enter、修饰键、空白、禁用均不提交；不将已接收请求恢复成待发草稿。
- 400 等明确拒绝保留可编辑输入；网络或 5xx 保留并锁定，GET 未见消息不能证明拒绝。活跃 Run 单独不能确认本次输入；只用新增同文 USER 消息核对接受，不自动 POST。
- 只读审批保持 canDecide 和逐项显式提交边界；202/CANCELLING 不作为停止完成。
- 1366×768、1920×1080、390×844 与 1366×600 已观察；手机列表可滚动、选中后自动收起，发送按钮首屏可达。真实 IME、缩放与软键盘仍待 T7。
