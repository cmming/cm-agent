# 技能试运行目标 Agent 下拉选择设计

## 背景

技能管理页的指定版本试运行要求输入目标 Agent UUID。手工复制 ID 容易出错，也不利于使用者确认所选 Agent 的模型配置。

## 目标与范围

- 将目标 Agent UUID 输入改为可访问的下拉选择。
- 选项来自现有 `/api/agents` 列表，仅展示已启用且 ID 有效的 Agent，并显示名称和模型。
- 处理加载中、空列表、权限不足和请求失败状态；未选择 Agent 时不可提交。
- 不调整后端 API、权限、审计、试运行流程或数据库。

## 非目标

- 不创建、启用或授权 Agent。
- 不发起真实模型试运行；浏览器验证仅检查选择控件及窄屏布局。
- 不改动已有登录配置或其他技能管理流程。

## 方案与约束

在 `skills.js` 中加载现有 Agent 列表并过滤不可作为运行目标的记录，使用 Agent 名称与模型名作可辨识标签，提交时仍传所选 Agent ID 到原试运行请求。服务端授权和启用状态校验仍是最终安全边界。表单样式沿用现有输入控件；状态提示保持中文并可由辅助技术播报。

## 验收标准

1. 已启用 Agent 可通过下拉选择，停用或无效记录不出现。
2. 无可用 Agent、权限缺失和列表请求失败时有明确提示且不能误提交。
3. 请求体/API 与服务端安全语义保持不变。
4. JavaScript 回归测试通过；真实浏览器可见并选择选项；390px 视口无横向溢出。
