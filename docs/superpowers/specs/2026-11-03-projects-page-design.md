## 背景与目标

现有本地项目能力被拆散在项目工作区、项目授权和页面样式三个历史工作包中，分别描述后端能力、授权语义和视觉优化。本组按页面重新整合 `projects.html`，让维护者从一个人口入口理解项目登记、文件工作台、会话、工具、审批和授权方式。

目标是让用户在同一个页面完成：选择本地项目、查看项目文件、新建项目会话、选择当前 Run 授权方式、处理变更/命令审批、停止或核验未知操作。页面不承担远程电脑执行，也不把项目目录权限描述成操作系统沙箱。

本组 R0 是按页面重组后的基线，不代表功能未实施；R1 在 2026-11-04 仅补全文档中的工具登记入口、异步未知状态、证据口径和跨组边界。

## 页面结构

1. **项目区**：添加项目、系统选择器、能力提示、手工登记固定工具目录、项目列表、包含归档开关和刷新。
2. **项目详情**：项目名称与元数据、改名、归档、状态提示、会话/文件视图切换。
3. **项目会话**：Agent 选择、新建会话、最近会话、消息、授权模式、审批卡、操作历史和停止。
4. **文件工作台**：目录列表、搜索、脱敏预览、文件引用和加载更多。
5. **边界说明**：固定 `project_*` 工具目录、项目根限制、命令继承 Server 运行账号、停止不等于回滚。

## 数据与调用链

浏览器选择项目 → 服务端校验项目 owner、tenant、状态和当前会话 → 新建会话时安装固定工具目录并为所选 Agent 补齐 grant → Run 快照固定项目、Agent、工具集合和授权模式 → 模型只能调用本轮冻结的 `project_*` 工具 → 文件/命令副作用前复核模式、提案版本/摘要、权限和审计 → 页面显示权威状态。

页面不直接访问本地文件系统。项目根、相对路径、文件元数据和脱敏正文都由服务端受控接口返回。浏览器提交的项目名称、模式、会话请求和审批结论都只是意图，不能替代可信身份和授权状态。

页面还保留“登记固定项目工具目录”兼容入口：仅在服务端 `capabilities.conversations` 允许时显示，调用 `POST /api/projects/tools`，由服务端同时校验 `project:manage` 和 `tool:grant`。该入口只登记固定定义，不向 Agent 自动授权；新建会话时的缺失 grant 补齐仍是独立步骤。

## 权限入口

| 页面动作 | 服务端最低权限 |
|---|---|
| 项目列表、详情、目录、搜索、预览 | `project:read` |
| 项目会话列表 | `project:read`、`agent:read` |
| 新建项目会话 | `project:read`、`agent:read`、`agent:run`、`project:manage`、`tool:grant` |
| 项目创建、改名、归档 | `project:manage` |
| 审批决定 | `agent:approve`、`agent:run` |
| 手工登记固定工具目录 | `project:manage`、`tool:grant` |

权限仍受 tenant、精确 owner、本机请求边界和功能开关约束；页面按钮显隐不是授权依据。

## 异步与未知状态

- 原生选择、项目创建、改名和归档都可能出现 `UNKNOWN`、`CREATE_UNKNOWN` 或版本冲突。
- 页面收到未知结果时必须提示重新读取列表或详情核对，不自动重复提交。
- 归档使用当前项目版本做条件更新；改名同样必须携带读取时版本。
- 项目创建和选择票据只允许一次消费；失败后需要重新发起明确操作，不能回放旧票据。

## 授权模式

| 页面名称 | 代号 | 项目内语义 |
|---|---|---|
| 请求批准 | `ASK_ON_EFFECT` | 只读操作可执行，文件变更、命令和未知副作用逐项确认 |
| 帮我自动批准 | `ASK_ON_RISK` | 低风险只读/无副作用提案可执行，高风险变更、命令和未知操作确认 |
| 完全访问 | `FULL_ACCESS` | 只对当前项目、当前 Agent、当前 Run 的已识别固定 `project_*` 工具自动执行 |

`FULL_ACCESS` 不表示 Server 任意路径、浏览器路径或自动提权。普通工具不得继承项目授权模式；设备客户端的账号范围完全访问见[本机客户端页设计](2026-11-03-local-client-page-design.md)。

## 安全与一致性

- 项目列表和详情始终携带 tenant/owner 上下文，不能通过猜测项目 ID 读取其他项目。
- 新建项目只接受系统选择器票据，不接受浏览器直接提交绝对路径；项目根保存为受保护信封。
- 项目会话固定项目和 Agent，不允许通过普通会话伪造项目模式。
- 文件变更先形成不可变计划和摘要，审批后条件应用；外部变更、版本漂移和部分失败必须失败关闭或标记 UNKNOWN。
- 命令和构建继承 Server 运行账号权限，可能访问项目外资源和网络；界面必须展示风险。
- 页面错误使用可读中文原因、稳定错误码和 `errorId`；敏感正文、绝对宿主根、命令原文和凭据不进入普通日志。

## 非目标

- 不把本地项目工作台扩展为远程设备控制页面。
- 不实现操作系统级沙箱、网络禁网或命令内部每个动作的逐项拦截。
- 不实现自动 Git、发布、桌面 GUI 自动化或多人协作。
- 页面样式调整不改变后端权限和业务合同。

## 验收标准

页面在全新登录和既有项目下均能正确显示能力；项目创建、选择、文件浏览、搜索、预览、引用、会话创建、固定目录手工登记、三种模式、审批、停止和错误状态可用；未知结果和版本冲突先核对；窄屏不遮挡主要操作；所有写操作和命令都能通过 Run、工具、提案、权限和审计证据追溯。
