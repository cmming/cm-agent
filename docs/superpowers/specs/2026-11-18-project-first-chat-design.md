# 项目优先聊天设计

日期 `2026-11-18` · 修订 `R0` · 模式 `mode=interactive`

范围为 CM Agent 控制台 v2 的目录项目优先聊天及普通聊天入口，任务编号 `T0` 至 `T4`。

## 背景与目标

聊天页原来先选 Agent 并加载该 Agent 的普通会话。项目页已经用目录项目组织会话，区分服务端电脑和已配对电脑。统一聊天入口后，操作顺序为选择目录项目、选择已有会话或选 Agent 新建会话。项目目录管理在本地项目页完成。

## 已确定的取舍

| 决定 | 问题 | 候选 | 采用 |
| --- | --- | --- | --- |
| Q1 | 项目定义 | 现有目录项目、可选目录项目、会话分组 | 复用现有两种目录项目，按部署能力提供。 |
| Q2 | 普通会话 | 保留普通聊天、所有新会话归项目 | 保留普通会话和新建、发送能力。 |
| Q3 | 页面职责 | 集中到聊天页、两页均可聊 | 聊天页承载会话，项目页负责登记、搜索及预览，链接到对应项目聊天。 |
| Q4 | 打开默认页面 | 恢复可访问项目、每次选择 | 同一浏览器按已认证租户和账号记住上次项目，显式项目链接优先。 |
| Q5 | 普通聊天入口 | 聊天页固定链接、全局导航同级入口 | 聊天页固定链接，地址可直接访问。 |
| Q6 | 文件版本引用 | 项目页带入草稿、聊天页添加选择器 | 从服务端电脑项目的预览携带相对路径、摘要与字节范围，选会话后加入草稿。 |
| Q7 | 发送机制 | 保留项目机制、改成流式输出 | 沿用同步提交、状态核对、审批和停止。 |
| Q8 | 归档会话 | 聊天页查看、项目页单独查看 | 聊天页支持包含已归档和只读会话历史。 |

## 访问与数据边界

`chat.html` 为项目入口，`?mode=ordinary` 打开普通聊天。指定目录项目通过来源和项目 ID 定位，鉴权依据为带专用请求头的服务端详情响应。历史项目偏好只保存这两个定位值，文件引用在同一文档的导航过程中交接。切换页面、来源或认证会话后失效。两类项目列表和会话归属由现有 API 决定，普通会话继续从 Agent 列表进入。

归档列表由「包含已归档」控制。显式链接可以打开仍有权读取的归档项目。归档项目读取消息和可读审批历史，活动项目提供新建、发送和审批操作。设备项目的能力、HTTPS 来源门禁、审批预览与版本校验继续应用于该项目来源。

本次范围覆盖 `T0` 至 `T4` 的页面与文档，使用现有后端实体、持久化及运行方式。
