# 技能管理页面美化设计

## 背景与目标

现有技能管理页保留了完整的导入、查看资源与启停能力，但详情区与导入区在网格中分散，列表只表达名称和状态，使用者难以快速判断当前对象、版本与下一步。

本次将页面优化为符合控制台“受控工作台”风格的连续流程：选择技能、核验固定版本及资源、按权限启停，必要时导入新 ZIP 包。

## 范围

- 优化 `skills.html` 的标题、列表、详情占位和导入布局。
- 优化 `skills.js` 对技能状态、当前选中项、资源预览入口与详情元数据的安全渲染。
- 在 `multipage.css` 中补齐技能页桌面、平板和窄屏布局及交互状态。
- 更新 v2 静态资源版本参数，避免浏览器继续使用旧 CSS 或脚本。

## 非目标

- 不修改技能导入、资源读取、启停 API、权限校验或审计逻辑。
- 不增加技能编辑、删除、版本回滚或新的后端数据字段。
- 不改变其他页面的业务结构。

## 方案与约束

页面采用桌面端“左侧固定资源上下文、右侧连续详情与导入”的布局；900px 以下改为单列。状态色只表示服务端的启用状态，列表选中态使用既有治理蓝。所有动态内容继续通过 `textContent` 创建，不使用 HTML 字符串拼接。

## 验收标准

- 初始状态清楚提示如何开始；列表明确显示名称、描述和启用状态。
- 选择技能后可看见版本、实际可用性和资源预览入口；拥有 `skill:write` 时仍可启停。
- 导入表单仍只接受 ZIP，并保留“导入后默认未启用”的提示。
- 900px 和 600px 以下不出现双栏挤压、信息溢出或不可触达操作。
