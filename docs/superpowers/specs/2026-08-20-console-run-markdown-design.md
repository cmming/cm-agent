# 控制台运行输出 Markdown 渲染设计

## 背景

运行页已经能够实时接收模型输出，但输出统一以纯文本显示，无法保留模型回答中的标题、列表、代码块和表格等结构，影响调试和结果阅读效率。

## 目标

- 对实时输出和历史运行详情中的模型结果渲染受限 Markdown。
- 保持流式增量接收与最终持久化结果校正逻辑不变。
- 禁止模型输出以原始 HTML 进入页面，维持控制台的 XSS 防护边界。

## 范围

- 在控制台脚本中实现 DOM 方式的受限 Markdown 渲染器。
- 为 Markdown 内容补充标题、列表、引用、代码块、表格、强调和链接样式。
- 补充控制台资源测试与本组过程文档。

## 非目标

- 不引入外部 CDN、第三方浏览器依赖或服务端 Markdown 转换。
- 不支持原始 HTML、图片、嵌套列表、任务列表、数学公式或 Mermaid 图表。
- 不变更运行接口、SSE 协议、数据库结构和持久化内容。

## 方案

渲染器读取 Markdown 原文后构造 `DocumentFragment`，再通过 DOM API 写入输出容器。支持常用块级结构和行内强调；代码和普通文本仅作为文本节点写入。链接只允许 `http`、`https`、`mailto` 及页内锚点协议，外部链接设置 `noreferrer noopener`。

流式场景在每次收到增量后，以当前完整原文重新生成输出内容。这样即使 Markdown 标记跨越 SSE 分片边界，也会在标记完整后正确呈现；最终完成事件仍以持久化结果重新校正。

## 约束

- 禁止使用 `innerHTML`、`insertAdjacentHTML` 或模型内容构造属性名、事件处理器。
- 输出内容不得影响控制台其他区域的 DOM 或样式。
- Markdown 仅提升显示效果，不能改变模型输出的原始持久化值。

## 验收标准

1. 实时与历史输出可展示标题、列表、引用、代码块、表格、粗体、斜体、删除线和受限链接。
2. 原始 HTML 与不安全链接以普通文本显示，不能执行脚本。
3. 流式 SSE 与运行详情加载仍可正常工作。
4. 控制台资源测试和脚本语法检查通过。
