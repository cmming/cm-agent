# Skill 试运行结果预览设计

## 背景

当前指定版本试运行接口返回 Run 标识、试运行门禁状态和审批状态，但前端无法直接展示本次运行的最终输出、执行状态、错误和工具摘要。使用者需要切换运行记录定位结果，且页面刷新后缺少可恢复的预览。

## 目标

- 由试运行 API 返回受控、脱敏的 Run 结果预览。
- 技能管理页展示运行状态、输出/错误和最小化工具调用摘要，并在读取试运行详情时恢复预览。
- 不改变 TEST Run 的执行、审批、发布门禁、租户隔离或数据库结构。

## 范围

- `SkillTrialService` 提供经已有试运行所有权检查后的 Run 详情读取。
- `SkillResponses` 增加兼容性扩展字段 `preview`，只映射已脱敏持久化结果。
- 试运行创建、审批恢复和有权读取详情的 Controller 响应包含预览。
- 技能管理 v2 页面以纯文本 DOM 渲染结果，并适配窄屏布局。
- 补充服务层、接口层、控制台测试及四份任务记录。

## 非目标

- 不改变模型调用、工具授权、审批生命周期或技能发布门禁。
- 不显示原始工具输入、tenant/principal 标识或工具调用 ID。
- 不新增数据库迁移、权限或持久化字段。
- 不把测试 Fake Runtime 的预览视为真实模型验收。

## 数据与权限约束

- 预览只从现有 Run 持久化详情读取；Run 数据在持久化边界已经脱敏。
- 详情读取继续校验试运行归属和租户；Controller 同时要求 `skill:read` 与 `agent:read`。
- 工具摘要只包含工具名称、脱敏输入/输出摘要、状态、耗时、授权状态和脱敏错误说明。
- 动态结果通过 `textContent`/文本节点输出，不解释为 HTML。

## 验收标准

1. 开始试运行和审批恢复响应包含预览状态、输出/错误与工具摘要。
2. 查询单次试运行详情可恢复预览，未授权读取仍被拒绝。
3. 前端正常显示成功、失败/等待及无工具调用状态，且结果文字不执行 HTML。
4. Java 定向测试、控制台测试和真实浏览器流程通过；390px 视口不产生横向溢出。
5. `docs/release-notes.md` 与同主题计划、实现说明和进度账本同步。
