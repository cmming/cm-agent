# 首个 Agent 引导设计

## 背景

空租户在能力总览中默认看到“创建 Agent”，但 Agent 必须绑定当前租户内已启用的模型配置，容易在提交前置条件上受阻。

## 目标与范围

在 v2 能力总览按资源状态展示下一步：无模型配置时配置首个模型，已有但未启用时引导启用，已有启用模型时创建 Agent。引导不阻断已有管理员继续使用其他页面。

## 非目标

不新增后端接口、持久化状态、教程模式、浏览器存储、权限或审计语义。

## 约束与验收

保留现有页面 URL、表单 ID、租户隔离和 API。总览加载模型配置后能更新首要操作；所有 v2 页面引用新的脚本和样式版本；控制台资源测试通过。
