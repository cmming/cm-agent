# 控制台原型对齐设计

## 背景与目标

现有 v2 控制台已具备真实的多页面资源管理与运行交互，但页面顶栏和内容层级与“CM Agent 运营控制台”原型不一致。本次将七个 v2 页面统一为原型的侧栏、窄顶栏、标题操作区与卡片工作区视觉结构。

## 范围

- 调整能力总览、Agent 管理、模型配置、工具治理、会话聊天、运行记录和审计日志的页面骨架。
- 复用原有 API、表单、权限和数据加载逻辑；不引入模拟数据或新接口。
- 统一响应式规则，使窄屏下仍可访问标题、操作和导航。

## 非目标

管理区补充验收：Agent 与模型配置左栏桌面宽度为 300px，右栏连续排列详情和表单；普通字段双列，系统提示词与 API Key 通栏。中等屏幕左栏收窄为 260px，900px 以下管理区单列，600px 以下字段单列。保留工具页独立布局规则，不将其强制改为相同双栏。

本任务实施顺序见 `../plans/2026-09-16-console-prototype-alignment.md`，实际结果见实现说明与进度账本。

- 不改变登录、权限、审计、租户隔离或业务请求语义。
- 不修改 v1 控制台和服务端接口。

## 方案与验收

各页面顶栏只保留工作区定位、运行状态、管理员标识与退出操作；页面标题及主操作移动到内容区。公共 CSS 负责间距、面板圆角、运行页深色调试区和会话页布局，现有 DOM 标识与脚本事件保持兼容。验收包括七页均加载公共样式、导航次序一致、主操作可用且移动端没有横向布局溢出。
