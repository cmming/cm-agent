# 桌面版项目聊天账本

日期 2026-11-18 · 主题 `desktop-project-chat` · 修订 `R2` · `mode=interactive`

## 当前范围与依据

本轮为交互式设计，覆盖 Windows x64 桌面试装、聊天页选文件夹、固定项目会话、流式发送、三档授权下的文件修改、命令执行和项目片段外发。试装使用已配置的 JDBC。Git 基线为 `c8e1ec3`。本轮文档未提交，运行实例无发布操作。

`git log -8 --format='%h %s'` 和 `git show --stat --oneline 2aff9b4` 确认 `c8e1ec3` 撤销了前一次项目优先聊天改造。旧改造只涉及控制台及文档，项目发送保持同步。历史账本记录的内网验证为同机项目纯文本回复，工具调用为零。撤销原因未在提交说明中记录，旧验证不能覆盖本次新增的桌面安装和真实工具运行。

通过 `Invoke-WebRequest` 只读访问内网目标。`chat.html`、`projects.html`、`assets/app.js` 和 `console/v2/assets/client-projects.js` 均返回 HTTP 200，响应字节的 SHA-256 与本地同名资源一致。此次只读取页面和静态资源，未建立登录会话或执行流式请求。

通过 `codegraph explore` 核对会话控制器、会话服务、同机项目服务与数据库方言入口，并对照[配置说明](../../configuration.md#本地项目开发工作区)。当前 SSE 从固定会话绑定恢复项目上下文，项目页面初次发送走同步接口。同机项目已提供原生目录选择、文件变更和受控命令，但创建项目会话会尝试准备 Agent 工具授权，桌面普通用户入口需要独立处理这一权限依赖。

复核 [操作审批策略](../../../cm-agent-core/src/main/java/com/cmagent/core/security/OperationApprovalPolicy.java)、[工具目录](../../../cm-agent-server/src/main/java/com/cmagent/server/runtime/LocalProjectToolCatalog.java)和[模型工具桥接](../../../cm-agent-agentscope-adapter/src/main/java/com/cmagent/agentscope/AgentScopeToolBridge.java)。现有同机项目三档权限控制文件和命令工具调用。文件工具结果仍可进入在线模型请求，现有工具审批未覆盖模型发送。这是本次 D8、D11 新增的业务能力。

## 决定记录

| 编号 | 用户选择 | 影响 |
| --- | --- | --- |
| D1 | 采用本机一体版 | Java 后端与项目执行在使用者电脑，原有 LAN 站点仅用于对照。 |
| D2 | 采用固定项目会话 | 一个项目可有多个会话，每个会话从创建起固定使用该项目。 |
| D3 | 首版需要改文件和运行命令 | 纳入改动、执行和恢复场景，不能用纯文本验收替代。 |
| D4 | Windows x64 首发 | 安装包自带 Java，验收集中在 Windows x64。 |
| D5 | 命令采用三档 | 参考设备管理模式，由档位确定是否询问。 |
| D6 | 文件写入采用三档 | 采用相同授权模式，预览、执行和审计贯穿同一变更版本。 |
| D7 | 持久化改造后移 | 桌面版试装继续用既有 JDBC/Flyway。 |
| D8 | 在线模型使用项目数据也采用三档 | 模型发送边界新增权限判断。 |
| D9 | 沿用工具链白名单 | 所有档位均受已配置工具链与参数限制。 |
| D10 | 默认高风险时询问，每轮锁定 | 调档从下一轮生效，审批恢复沿用原模式。 |
| D11 | 所有项目片段对在线模型均按高风险 | 两档询问需要预览实际片段和模型，完全访问仅在本轮获准范围内自动发送。 |
| D12 | 先做已配置 JDBC 的试装 | 免数据库配置的普通用户安装后续验收。 |

2026-11-18 修订记录。`R0` 采用 D1–D3。`R1` 采用 D4–D8，增加 Windows x64 平台、统一三档授权并后移持久化改造，影响 T1、T4–T6。`R2` 采用 D9–D12，明确白名单、默认档与时效、在线模型风险和 JDBC 试装条件，影响 T1、T3–T6。历史运行证据仅覆盖现行页面和已有能力。
