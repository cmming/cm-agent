# 控制台原型对齐实现说明

## 实现结果

七个 `console/v2/*.html` 页面均采用“工作区面包屑 + 系统状态 + 内容标题区”结构。各资源页的顶部按钮定位原有表单；能力总览和运行记录链接到既有工作台；会话聊天的顶部按钮通过 `app.js` 调用与侧栏同一套创建会话逻辑。

`multipage.css` 统一了原型对应的 76px 顶栏、内容宽度、标题层级、卡片间距、资源管理双栏、运行页深色调试面板及移动端布局。Agent 与模型配置页将详情和表单置于 `management-detail-stack`，避免左侧资源列表高度把右侧表单推到下一网格行。`app.js` 资源版本同步更新为 `2.0.19`，使浏览器在发布新版页面时重新请求新增会话顶部操作的绑定脚本。所有变更仅涉及静态页面及其客户端绑定，未改变服务端 API、认证或数据模型。

## 与原方案的差异

后续管理区修正：`agents.html`、`model-configs.html` 使用 `management-form-grid` 与字段容器将标签、输入和帮助文字作为整体排版；API Key、系统提示词及表单级操作通栏。公共样式左栏改为 300px，间距 14px，详情增加行分隔线，资源选中项改为浅蓝底。七页公共样式版本为 2.1.1。`ConsoleResourceTest` 新增结构回归测试。现有工具页的专用单列规则继续生效。
