# V3 工作区视觉规范

本规范适用于 `/console/v3/`，沿用已确认的 Sites 布局。V1、V2 的既有视觉与入口保持独立。

## 颜色与字阶

| 角色 | 值 | 用途 |
|---|---|---|
| 主背景 | `#ffffff` | 对话和管理详情 |
| 侧栏 | `#f7f7f8` | 稳定导航与项目会话 |
| 次级表面 | `#f3f3f4` | 选中项和分组 |
| 正文 | `#252528` | 主要阅读内容 |
| 说明 | `#67676e` | 可读辅助信息 |
| 边界 | `#e8e8eb` | 分隔与控件 |
| 主操作 | `#29292c` | 发送、保存和确认 |
| 成功 | `#24744d` | 实际成功状态 |
| 风险 | `#94641c` | 待处理风险状态 |

基础正文 16px，控件 14px，紧凑说明 13px，元数据 12px，管理页标题 26px。字体使用系统无衬线，代码使用 Cascadia Code / Consolas。常规控件圆角 8px，面板 10px，输入容器使用更宽松的圆角。

## 布局与交互

- 桌面侧栏 256px，顶部 69px，上下文栏 340px；聊天阅读列不铺满宽屏。
- 1050px 以下上下文覆盖主区；760px 以下导航收为抽屉，顶部 59px。
- 覆盖层开启后隔离背景焦点，约束双向 Tab，支持 Escape 和关闭后恢复焦点。
- 聊天列表、消息、上下文各自滚动。发送与停止继续使用共享业务状态；不能用样式覆盖权威 `hidden` 或禁用状态。
- 轻微动效只用于导航与上下文展开，遵守减少动态效果偏好；不用循环装饰动画。
- 管理页保留真实详情、编辑、授权、调试、删除、技能版本和分页等操作；布局变化不合并业务职责。

## 实现边界

V3 共用同源 API、Cookie、内存 JWT 兼容路径、权限、租户和审计链路。原型中的模拟会话、文件、模型选择和浏览器持久化数据不进入生产前端。真实目录、设备、审批和运行状态由服务端返回。

配套机器可读 token 位于本目录 `.impeccable/design.json`；实际验收与限制见[实施账本](../../superpowers/progress/2026-11-21-console-v3-workspace-ledger.md)。
