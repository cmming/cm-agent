# V3 聊天工作区

模式：Operate。用户已指定沿用独立 Sites 的 Codex 式布局，并要求保留当前功能、连接真实后端。使用代码驱动实现，不另行选择视觉方向。

## Direction contract

THESIS：项目和会话构成持续工作的导航上下文，对话占据主区；模型、工具、技能、运行和审计保持可直接访问的管理入口。

OWN-WORLD：沿用已确认 Sites 的白色画布、浅灰侧栏、石墨文字、细灰边框和轻圆角。成功、风险、错误使用有实际业务含义的状态色。中文采用系统字体，代码使用等宽字体。

STORY：登录后进入聊天，从真实 Agent 和项目开始工作，按需核对资料、审批和运行状态；切换管理页面时保持同源认证与明确版本路径。

FIRST VIEWPORT：左侧 256px 项目与会话栏；顶部 69px 当前工作区；中间自适应聊天与底部输入；右侧 340px 上下文按需展开。窄屏采用导航抽屉和上下文覆盖层，保留所有真实控件。

FORM：以既有 V2 业务 DOM 和客户端模块为功能基线，V3 负责版本路由与布局。模型取自 Agent 绑定，文件来自受控接口，审批遵守真实状态；不复制原型的演示数据和浏览器持久化会话。

FINISH：检查桌面与手机布局、真实接口和关键交互，独立复核并同步本工作区设计文档。实际验证、限制和提交状态仅记录在本任务账本。
